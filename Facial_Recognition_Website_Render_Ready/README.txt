# Facial Recognition — PCA + KNN Web App

A clean white Flask website built around the supplied Python project approach:
Olivetti Faces dataset, PCA (100 components), and K-Nearest Neighbors (k=3).

## Important scope
This is a classroom/demo recognizer. It predicts one of the 40 numeric identity
classes in the Olivetti Faces dataset. It does **not** identify a person's real
name, verify identity, or provide production-grade face recognition. Uploaded
images are resized to 64x64 grayscale; no face detector/cropper is included, so
use a clear, front-facing, closely framed face for the most meaningful demo.

## Run on Windows
1. Install Python 3.10 or newer.
2. Extract this ZIP.
3. Open the extracted folder in VS Code.
4. Open Terminal and run:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   python app.py
   ```

5. Open http://127.0.0.1:5000 in your browser.

The first run downloads the Olivetti Faces dataset through scikit-learn and
trains PCA + KNN. Internet access is required for that first dataset download.
Later runs use scikit-learn's local dataset cache.

## Project structure
- `app.py` — Flask backend, PCA/KNN training, image upload and prediction API
- `templates/index.html` — website layout
- `static/css/style.css` — clean white responsive design
- `static/js/app.js` — upload interaction and dashboard data
- `static/images/` — visualizations generated by the supplied Python scripts
- `requirements.txt` — Python dependencies

## Privacy
The app runs locally on your computer. Uploaded images are processed in memory
by the local Flask server and are not saved to disk by this application.


## Deploy publicly on Render
1. Upload the contents of this folder to a GitHub repository (keep app.py,
   requirements.txt, templates/, and static/ at the repository root).
2. In Render choose New > Web Service and connect that GitHub repository.
3. Use:
   - Language: Python 3
   - Build command: pip install -r requirements.txt
   - Start command: gunicorn app:app
   - Instance type: Free (if available for your account/region)
4. Deploy. Render will provide an HTTPS onrender.com URL.

The app uses the Olivetti dataset download on first model initialization.
The first live request can take longer while the dataset is downloaded and
the model is trained. Free services may sleep after inactivity and take time
to wake up again.
